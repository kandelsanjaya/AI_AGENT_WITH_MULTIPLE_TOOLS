## 🚀 Quick Start

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&weight=500&size=16&duration=1600&pause=400&color=34D399&center=false&vCenter=true&width=500&lines=%24+Get+running+in+under+2+minutes" alt="quick start"/>

### 1. Prerequisites

- Python 3.11+
- A [GROQ API key](https://console.groq.com/) (free tier available)

### 2. Clone & Install

```bash
git clone https://github.com/kandelsanjaya/AI_AGENT_WITH_MULTIPLE_TOOLS.git
cd AI_AGENT_WITH_MULTIPLE_TOOLS
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 3. Configure Environment

Create a `.env` file in the project root:

```env
GROQ_API_KEY=gsk_your_key_here
```

> ⚠️ **Never commit your `.env` file.** It is already listed in `.gitignore`.

### 4. Run the App

```bash
streamlit run DasaAI.py
```

Open your browser at `http://localhost:8501`.

## 🔒 Security & Telemetry

- 🔐 **Salted Password Hashing** — passwords are secure-salted and hashed via PBKDF2-SHA256 within the SQLite storage layer
- 📈 **Activity Log Logging** — user milestones and analytics tracked in a dedicated `activity_log` table
- 🛡️ **Multi-layer Guardrails** — intercepts, flags, and blocks malicious prompts before they reach the GROQ API
- 🧵 **Thread-safe Sessions** — session-isolated variables stored and loaded per authenticated connection
